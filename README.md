# 🚀 Featured Project

### 📚 [Library Management System](https://github.com/rohi-del/library-management-system)
Full-stack app where students borrow and return books and admins track overdue books and usage.

- **Stack:** Node.js, Express, MySQL, JWT, bcrypt
- **Highlights:** role-based access, SQL transactions with row locking to prevent double-issuing the last copy, JOIN and GROUP BY reports, late fine calculation
- **Data structures:** hand-written **Trie** (search autocomplete) and **LRU cache** (recently viewed books), with unit tests
